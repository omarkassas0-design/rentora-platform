# Rentora public assets

Copy this `public` folder into the root of your Rentora project.

Contents:
- `favicon.svg`: browser tab icon
- `logo/rentora-logo.svg`: Rentora wordmark
- `placeholders/car-placeholder.svg`: fallback image for cars without a photo
- `cars/`: local car photos can be added here
- `banners/`: promotional banners can be added here

Git tracks the placeholder files, so the empty asset directories remain in the repository.
